# B4-1 Portfolio

모바일 우선으로 만든 학습용 개인 포트폴리오입니다. 별도 빌드 과정이나 외부 런타임 라이브러리 없이 HTML, CSS, JavaScript만 사용합니다.

현재 이름, 소개, 프로젝트, 연락처 문구는 실제 사용자 정보가 제공되기 전까지 명확한 임시 문구로 표시됩니다. 공개 저장소 영역은 사용자가 지정한 GitHub 계정 `xifoxy-ru`를 사용합니다.

## 주요 동작

- 모바일 우선 레이아웃과 `768px`, `1024px` 반응형 구간
- 키보드로 사용할 수 있는 모바일 메뉴와 밝은/어두운 테마 전환
- 스크롤 `60px` 이후 헤더 강조, `300px` 이후 맨 위 버튼 표시
- `IntersectionObserver` 임계값 `0.2`를 사용한 섹션 표시와 모션 감소 설정 지원
- 이름, 이메일, 메시지를 검사하는 로컬 데모 양식
- 기존 Hero 소개 문장을 첫 로드에 한 번만 보여 주는 타이핑 효과와 모션 감소·무 JavaScript 대체 표시

문의 양식은 제출 이벤트와 화면 상태만 확인합니다. 입력한 내용은 이메일이나 외부 서비스로 전송되지 않으며 저장되지도 않습니다.

메시지 입력창은 최소 `8rem`, 최대 `40rem` 높이에서 세로 크기를 조절할 수 있습니다. 브라우저의 일반적인 우하단 모양을 유지하면서 잡을 수 있는 코너 영역을 약 26px로 넓혔습니다. 코너는 드래그하거나 `↑`/`↓` 키로 16px씩, `Shift`와 함께 48px씩 조절할 수 있습니다. `Home`은 최소 높이, `End`는 최대 높이로 이동합니다.

이메일 검사는 공백과 제어 문자, 꺾쇠괄호, `@` 개수, 빈 로컬·도메인, 로컬 부분의 시작·끝·연속 점, 도메인 빈 라벨과 시작·끝 하이픈, 두 글자 미만 접미사를 거부합니다. `name+tag@example.com`, `o'hara@example.co.uk`와 유니코드 글자를 포함한 로컬 부분은 허용합니다. 이는 입력 실수를 줄이는 실용적인 로컬 검사이며 RFC 전체 준수나 실제 주소·도메인의 존재를 확인하지 않습니다.

## GitHub 저장소 설정

`index.html`의 `#projects` 요소에 있는 `data-github-username` 값으로 공개 GitHub 사용자 ID를 설정합니다. 현재 사용자 승인에 따라 `xifoxy-ru`가 설정되어 있습니다. 값을 비우면 안내 상태만 표시하고 네트워크 요청을 보내지 않습니다.

설정 후에는 GitHub 공개 API에서 최근 업데이트 순으로 저장소를 최대 100개 요청합니다. 로딩, 성공, 빈 목록, HTTP 또는 네트워크 오류, 다시 시도 상태를 각각 표시합니다. 이는 첫 API 페이지에 한정된 표시이며 모든 저장소를 가져온다고 보장하지 않습니다.

저장소를 불러오면 언어 필터가 `전체`와 실제 응답에 포함된 언어를 표시합니다. 언어 값이 없는 저장소가 있으면 `언어 미지정` 선택지가 추가됩니다. 필터는 이미 받은 저장소만 화면에서 다시 분류하므로 선택할 때 GitHub 요청을 추가하지 않습니다. 새 응답에 현재 선택 언어가 없으면 `전체`로 돌아갑니다.

## 로컬 실행

```sh
make serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 기본 점검은 `make check`로 실행합니다.

## 파일 구성

- `index.html`: 페이지 구조와 콘텐츠
- `css/style.css`: 반응형 레이아웃과 테마
- `js/main.js`: 메뉴, 스크롤, 테마, 양식, GitHub 저장소 표시
- `images/`: 제품 이미지 자산

GitHub Pages에 배포할 때 필요한 제품 파일은 `index.html`, `css/`, `js/`, `images/`입니다. `README.md`, `Makefile`, `.gitignore`는 개발과 저장소 사용을 위해 함께 관리하지만 배포 결과에는 필요하지 않습니다. 배포와 원격 Git 작업은 이 로컬 구현 범위에 포함되지 않습니다.
